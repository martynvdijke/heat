## Context

Repository has accumulated hygiene debt: `git branch --merged main` lists three long-lived feature branches with no unique commits — `feat/heat-upgrades` (last commit 2026-04-18), `feat/multi-device-playwright` (2026-05-09), `feat/new-features-stats-trophies-controller-chat-oneoff` (2026-04-30) — all 4-5 months stale and safe to delete. Additional stale branches exist but are not fully merged: `renovate/all-minor-patch` (19 ahead / 3 behind), `renovate/github.com-swaggo-files-2.x`, `renovate/pin-dependencies`. A dead file `handlers/stats.go` (1 line, `package handlers`) remains while real handlers live in `handlers/stats_basic.go`, `stats_advanced.go`, `stats_incidents.go`, `stats_performance.go`, `stats_scope.go`. Generated Swagger (`docs/docs.go` 3594 lines, `docs/swagger.json`, `static/swagger.json`) is committed and regenerated by `task generate-swagger` (run by `task pre-push`), creating generated-vs-source ambiguity. `.gitignore` ignores `openspec/` (handled separately by `version-openspec-artifacts`) and `.opencode/` (repo skills), plus build/runtime outputs. `Taskfile.yml` has `clean` and `pre-push`. A workflow `.github/workflows/stale-branches.yml` already exists for ongoing detection.

## Goals / Non-Goals

**Goals:**
- Remove fully-merged stale branches and dead source file with non-destructive, verifiable steps.
- Align `.gitignore` to ignore only build/runtime outputs, not source-of-truth artifacts.
- Decide and document the committed generated Swagger policy with a CI staleness guard.
- Make cleanup repeatable via existing automation (`stale-branches.yml`) and `task pre-push`.

**Non-Goals:**
- Force-deleting unmerged work or pruning active renovate branches that Renovate still manages.
- Duplicating the `openspec/` ignore decision owned by `version-openspec-artifacts`.
- Changing runtime behavior or API surface; this is repository hygiene only.
- Switching Swagger generation tooling (still `swag` via `task generate-swagger`).

## Decisions

### D1: Delete only branches fully merged into main — never force-delete unmerged work

Rationale: `git branch --merged main` proves `feat/heat-upgrades`, `feat/multi-device-playwright`, and `feat/new-features-stats-trophies-controller-chat-oneoff` contain no unique commits — deletion is safe and remote is source of truth (recoverable via reflog/remote). Stale renovate branches (`renovate/all-minor-patch` 19 ahead / 3 behind, `renovate/github.com-swaggo-files-2.x`, `renovate/pin-dependencies`) are not fully merged and are only pruned after confirming `renovate.json` ownership and that Renovate will recreate them.
Alternatives: bulk delete all stale branches including unmerged — rejected because it risks data loss for in-flight work.

### D2: `handlers/stats.go` removal is safe because stats handlers live in `stats_*.go`

Rationale: `handlers/stats.go` is a 1-line dead file (`package handlers`); real handlers live in `handlers/stats_basic.go`, `stats_advanced.go`, `stats_incidents.go`, `stats_performance.go`, `stats_scope.go`. Verify with grep that no symbols are defined in `stats.go` before removal.
Alternatives: keep empty file as placeholder — rejected; empty package files cause confusion and drift.

### D3: Generated Swagger — recommend "commit + CI staleness check" over "gitignore + generate in build"

Rationale: Keep committing `docs/docs.go` (3594 lines, generated), `docs/swagger.json`, and `static/swagger.json` and add a CI step that runs `task generate-swagger` and fails if `git diff` is non-empty. This keeps `go install` and offline tooling working without requiring `swag` at build time, while preventing drift. The committed artifacts have a documented regeneration path (`task generate-swagger` / `task pre-push`).
Alternatives: gitignore generated Swagger and generate only in build/CI — valid but requires `swag` in every build environment; noted as alternative if the team prefers no committed generated code.

### D4: `.gitignore` should ignore build/runtime outputs, not source-of-truth artifacts

Rationale: Current `.gitignore` correctly ignores `heat`, `heat.db`, `heat.db-shm`, `heat.db-wal`, `heat-server`, `static/js/`, `vendor/`, `*.exe`, `*.test`, `*.out`, `node_modules/*`, `playwright.local.config.ts`, `test-results/*`, `playwright-report/*`, `playwright-report.zip`, `tmp/*`, `tools/`, `media/backups/`, `backups/`, `docs/*.md`, `openspec/`, `.opencode/`. The `openspec/` line is owned by separate change `version-openspec-artifacts` and is not duplicated here; `docs/*.md` staying ignored while `docs/*.go/json` are tracked is an open question (see below).
Alternatives: ignore all of `docs/` — rejected because `docs/docs.go` and friends are source-of-truth for committed Swagger under D3.

### D5: Automate stale-branch detection via existing `stale-branches.yml`

Rationale: `.github/workflows/stale-branches.yml` already exists — reference and use it rather than adding a new workflow. `Taskfile.yml` `clean` and `pre-push` remain the local hygiene entry points.
Alternatives: new dedicated workflow or Taskfile target — rejected as duplication.

## Risks / Trade-offs

- Deleting a branch someone still needs → only delete branches fully merged into `main` (verified via `git branch --merged main`); remote is source of truth and branches are recoverable from reflog/remote.
- Removing `handlers/stats.go` if it accumulates future code → grep for symbols defined in `stats.go` before removal; file is recoverable from git history.
- Regenerating Swagger needs `swag` installed in CI → install `swag` in the staleness check job; failure mode is a clear diff error.
- Renovate branches pruned while Renovate still needs them → confirm `renovate.json` ownership and that Renovate recreates branches; prune only after confirmation.
- `docs/*.md` ignore vs tracked `docs/*.go/json` confusion → explicitly call out as open question; no change to that line in this change.

2. Delete fully-merged stale branches (`feat/heat-upgrades`, `feat/multi-device-playwright`, `feat/new-features-stats-trophies-controller-chat-oneoff`) locally and remotely.

4. Grep `handlers/stats.go` for defined symbols; remove the dead file.
5. Update `.gitignore` to align with D4 (no duplication of `openspec/` line owned by `version-openspec-artifacts`).
6. Add CI staleness check that runs `task generate-swagger` and fails on `git diff` for `docs/docs.go`, `docs/swagger.json`, `static/swagger.json`.
7. Run `task pre-push` (formatting, tests, vet/vuln, TS compile, Go build, Swagger regeneration) and verify clean.
- Rollback: branches recoverable from reflog and remote; `handlers/stats.go` recoverable from git history; `.gitignore` and Swagger policy revertible via git revert.
