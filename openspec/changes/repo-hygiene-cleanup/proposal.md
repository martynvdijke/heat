## Why

Stale merged branches (`feat/heat-upgrades` last commit 2026-04-18, `feat/multi-device-playwright` 2026-05-09, `feat/new-features-stats-trophies-controller-chat-oneoff` 2026-04-30 — all fully merged into `main` per `git branch --merged main` and 4-5 months stale), a dead source file (`handlers/stats.go` containing only `package handlers` — real handlers live in `handlers/stats_basic.go`, `stats_advanced.go`, `stats_incidents.go`, `stats_performance.go`, `stats_scope.go`), and committed generated Swagger artifacts (`docs/docs.go` 3594 lines, `docs/swagger.json`, `static/swagger.json` regenerated by `task generate-swagger` which `task pre-push` runs) create branch clutter, dead-code confusion, and generated-vs-source drift.

## What Changes

- Delete fully-merged stale branches: `feat/heat-upgrades`, `feat/multi-device-playwright`, `feat/new-features-stats-trophies-controller-chat-oneoff` (verified via `git branch --merged main` with no unique commits); prune stale renovate branches (`renovate/all-minor-patch` 19 ahead / 3 behind, `renovate/github.com-swaggo-files-2.x`, `renovate/pin-dependencies`) after confirming Renovate (`renovate.json` exists) will recreate them if needed.
- Remove dead file `handlers/stats.go` (1-line `package handlers` stub; verify with grep that no symbols are defined there before removal).
- Align `.gitignore` with reality: currently ignores `heat`, `heat.db`, `heat.db-shm`, `heat.db-wal`, `heat-server`, `static/js/`, `vendor/`, `*.exe`, `*.test`, `*.out`, `node_modules/*`, `playwright.local.config.ts`, `test-results/*`, `playwright-report/*`, `playwright-report.zip`, `tmp/*`, `tools/`, `media/backups/`, `backups/`, `docs/*.md`, `openspec/`, `.opencode/` — fix build/runtime ignores vs source-of-truth (see design D4 and open question on `docs/*.md`).
- Decide committed generated Swagger: recommend keeping `docs/docs.go`, `docs/swagger.json`, `static/swagger.json` committed with a CI staleness check that regeneration produces no diff (keeps `go install`/offline use working); document alternative of gitignoring and generating at build. The `openspec/` ignore line is handled by separate change `version-openspec-artifacts` — not duplicated here but noted for overlap.
- Reference existing `.github/workflows/stale-branches.yml` for ongoing automation; `Taskfile.yml` already has `clean` and `pre-push`.
