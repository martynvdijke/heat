How It Works

                                

                                    
After each race is saved to history, an email with the full results will be sent to all racers who have an email address configured.

                                    
The email includes each driver's position, points, and fastest lap status in an HTML table.

About OTel

                                

                                    
OpenTelemetry provides observability for your application. Configure an OTLP endpoint to send traces, metrics, and logs to a compatible collector.

                                    
Changes take effect on the next application restart. The OTLP HTTP protocol is used for exporting.
