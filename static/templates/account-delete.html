Delete your account

Last updated: {{.Legal.LastUpdated}}

HEAT has two separate kinds of account. Both can be deleted without asking the operator, in the mobile app or on the website. This page also explains what is removed and what is kept.

Racer identity

A racer identity is the profile with your name, car, team, results and upgrades. It is separate from an admin account.

In the mobile app

  1. Open the HEAT app and sign in as the racer.
  2. Open Settings.
  3. Choose Delete racer identity.
  4. Type DELETE in the confirmation field and confirm. The app signs you out on that device afterwards.

On the website

  1. Open the racer sign-in page and request a one-time link for the email address on file.
  2. Follow the link in the email.
  3. On your profile, choose Delete my racer identity.
  4. Type DELETE and confirm.

If the email address on file is no longer reachable, use the email fallback below. The operator can verify ownership another way and perform the deletion.

Admin account

An admin account is the username and password used to manage the championship. Deleting it does not delete race data.

In the mobile app

  1. Open the HEAT app and sign in as Race Director.
  2. Open Settings.
  3. Choose Delete admin account.
  4. Type DELETE and confirm. Every admin web session is revoked.

On the website

The web admin panel does not currently have a delete control. Sign in with the mobile app as race director, or use the email fallback below. The API endpoint is DELETE /api/account; it requires a signed-in admin session and a JSON body {"confirm":"DELETE"}.

Last admin. The last remaining admin account cannot be deleted, because that would leave the instance with nobody able to administer it. Create or promote another admin first.

What is removed

Racer identity

  • the racer profile: name, profile picture reference, car, team assignment, points, rank and position;
  • every email address stored for racer sign-in;
  • Telegram links (chat identifier), pending link tokens and per-chat notification/RSVP preferences;
  • player session tokens and device names;
  • upgrades, legend abilities, achievements, derived racer statistics and driver-share links;
  • live gameplay records: heat cards, gear shifts, lap and sector records, turbo logs, race events and race radio entries.

Admin account

  • the admin row: username, password hash, recovery email, OIDC subject and authentication method;
  • password-reset tokens issued for that admin;
  • every admin web session, which is revoked immediately.

What is kept

  • Historical results. Race results and round scores are part of the championship record. When a racer identity is deleted, those rows are detached from the person and the stored racer name is replaced with Deleted racer. They no longer link to an account, email address or Telegram chat.
  • Race, track, season and team data. Deleting an admin account does not delete race data, and deleting a racer identity does not delete the races they took part in.
  • Backups. A database backup taken before the deletion can still contain the old data until that backup is pruned under the instance's backup retention setting (seven backups by default). Backups are used only for disaster recovery.
  • Server logs. Access and error logs may still contain request metadata, including IP addresses, for the period configured in the instance's log settings.

Timing

Deletion takes effect immediately for the live database and signs out the affected sessions. Backups and logs disappear according to their own retention periods described above. You do not need to create a new account to ask a question about a deletion.

Say whether you want the racer identity or the admin account deleted, and include the racer name or admin username. Never send your password.

Export first

Both account types can download a JSON copy of their data before deletion. In the mobile app this is under Settings; the API endpoints are GET /api/me/export and GET /api/account/export. Exports never contain password hashes or session tokens.
